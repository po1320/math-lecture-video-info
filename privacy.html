Math Lecture Video 안내

개인정보처리방침

Math Lecture Video는 운영자 본인의 수학 강의 업로드와 게시 정보 확인을 위해 사용하는 로컬 프로그램입니다.

접근하는 정보와 목적

Google OAuth 승인 결과, 선택된 YouTube 채널의 ID·이름, 해당 채널의 영상 목록·제목·설명·태그·공개 상태·처리 상태를 사용합니다. 운영자가 지정하고 검토한 영상과 썸네일을 YouTube에 전송하고, 승인한 문구와 자료 링크를 설명에 반영합니다. 요청한 권한 묶음에 댓글·평가·삭제 권한이 포함되더라도 현재 프로그램은 이 기능을 호출하지 않습니다.

저장과 보호

인증 토큰과 업로드 세션 주소는 운영자 PC의 Windows 계정 암호화 저장소에 보관하고, 계정 접근 권한을 확인합니다. 게시 ID·검증 결과 등 운영 기록은 로컬 작업 환경에 보존합니다. 인증 토큰을 공개 저장소·영상 설명·이 안내 사이트에 넣지 않습니다.

전송과 사용 제한

인증 및 YouTube 작업에 필요한 요청은 Google의 공식 OAuth·YouTube API에 보냅니다. 이 업로드 프로그램은 Google 사용자 데이터를 판매하거나 광고 타깃팅·일반 AI 모델 훈련에 사용하지 않습니다. Google API 정보 사용은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

보관과 연결 해제

토큰은 연결 유지 동안 보관하며, 만료·회수되면 재승인 없이 권한을 확대하지 않습니다. Google 계정의 서드 파티 연결에서 접근 권한을 회수할 수 있습니다. 로컬 토큰·기록의 제거는 운영자가 별도로 처리합니다. 연결 해제는 기존 YouTube 영상을 자동 삭제하지 않습니다.

이 정적 안내 사이트에는 로그인·쿠키 추적·방문자 분석 기능이 없습니다. 호스팅 제공자의 일반 처리에는 해당 제공자의 정책이 적용됩니다.
